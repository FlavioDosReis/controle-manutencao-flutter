## 📱 Sobre o Projeto

O **Controle do Tempo de Manutenção de Veículos** é um aplicativo desenvolvido em Flutter para auxiliar a empresa **Carrão Auto Peças** no controle e organização dos serviços de manutenção realizados nos veículos.

A aplicação permite registrar um serviço, iniciar o acompanhamento do tempo de manutenção, pausar, continuar e finalizar o serviço. Também é possível consultar o histórico das manutenções realizadas.

O projeto foi desenvolvido buscando criar uma solução simples, organizada e fácil de utilizar no dia a dia da empresa.

---

## 🎯 Objetivo

O principal objetivo do aplicativo é facilitar o controle do tempo utilizado nos serviços de manutenção de veículos.

A aplicação permite acompanhar o andamento dos serviços e manter um histórico das manutenções realizadas, contribuindo para uma melhor organização dos processos internos.

## 🖥️ Principais Telas

O aplicativo possui telas desenvolvidas para facilitar a utilização e o acompanhamento das manutenções.

Apresenta as principais opções do aplicativo e permite iniciar uma nova manutenção ou consultar o histórico.

Tela utilizada para iniciar um novo serviço de manutenção.

### ⏱️ Manutenção em Andamento

Permite acompanhar o tempo do serviço, além das opções de pausar, continuar e finalizar a manutenção.

Apresenta os serviços que já foram finalizados, permitindo consultar as manutenções realizadas.
